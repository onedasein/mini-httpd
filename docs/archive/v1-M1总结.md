# 04 · M1 总结（阻塞式 HTTP，v1）

模版来自交接稿 §7；「我实际跑通的」一栏全部填了**实际输出**，不是期望值。

## 我实际跑通的

- **echo（M0/T0.3）**：`printf 'hi\n' | nc -N` 通过；短读现场看到 **3 次 recv（4096/4096/1808）**；
  `cmp` 回显 10000 字节完全一致。
  两个「反面教材」的现场结论：**① 常规会话后重启不会 `EADDRINUSE`**（TIME_WAIT 在客户端临时端口；要复现必须让服务端当主动关闭方，
  且 `SO_REUSEADDR` 只对「旧 socket 也带该选项」的 TIME_WAIT 放行）；**② 这个 echo 在 `SIG_DFL` 下 0/20 被 SIGPIPE 杀死**
  （结构上碰不到 EPIPE；机制另用最小复现钉死：无 `SIG_IGN` → exit 141，`SIG_IGN` → 存活）。
- **HTTP v1（M1）**：`bash tests/run.sh` → **55/55**（debug 与 ASan+LeakSanitizer 双跑）；
  `curl -i /` 200；`HEAD` 137 字节（只有头）；`405` 带 `Allow`；`414`（2500B URI）；`431`（20000B 单行 + 70KB 总量）；
  `404`；路径穿越（`--path-as-is /../Makefile`、`%2e%2e%2f`、`%00`）全部 400 且不泄漏内容；
  指向 `/etc/passwd` 与 `../Makefile` 的符号链接 **403**；10MB 传输 `cmp` 一致。
- **ASan/UBSan**：`make asan` + `ASAN_OPTIONS=detect_leaks=1` 跑全套 **全绿、exit 0**；
  valgrind 独立复核 `ERROR SUMMARY: 0 errors` + `All heap blocks were freed`。
- **M2 的靶子**：慢客户端（连上不发数据）能拖死全服 —— 服务端停在 `wchan=do_sys_poll`，
  第二个客户端 `curl -m 3` 拿到 `000`/exit 28；慢客户端一走立刻 1.9ms 恢复。

## 卡住过的地方（含 man/RFC 出处）

| 现象 | 我一开始以为 | 实际原因 | 出处 |
|---|---|---|---|
| 重启 bind 失败 | 端口没释放 | TIME_WAIT 占着四元组；而且要看它落在**哪一端**，以及旧 socket 有没有 `SO_REUSEADDR` | `man 7 tcp` |
| 连接卡住不动 | 客户端没发数据 | 串行 accept，慢客户端阻塞全服（本版故意保留） | `man 7 socket`（listen backlog / accept 语义） |
| 响应被截断 | 客户端 bug | write 短写没循环 | `man 2 write` |
| 客户端一断服务端就死 | 内核 bug | SIGPIPE 默认杀进程；且要先确认沙箱没把它继承成 `SIG_IGN` | `man 7 signal`、`man 2 send`（`MSG_NOSIGNAL`） |
| **所有 CRLF 请求 400，裸 LF 却 200** | header 循环写错了 | `next_line` 吃掉 `\r` 却没回退 `eol` → 空行被算成「长度 1 的行」 | 自己写的行切分；用 gdb 在 return 上打点定位（见 03-审查报告 B1） |
| `realpath` 隐式声明 | 只差一个 feature macro | 是「XSI 选项组 + 漏 include `<stdlib.h>`」两件事叠一起 | `/usr/include/stdlib.h:934` |

## 审查里我自己的代码真正中招的

1. **B1 CRLF 解析**（真 bug，会让服务器对正常 curl 全返 400）：`eol` 未回退。已修 + 已加逐字节 / CRLF / 裸 LF 三类用例。
2. **B2 `realpath` 声明**（编译期就挡住，没流到运行时）：`_XOPEN_SOURCE 700` + `stdlib.h`。
3. 其余 8 个维度（短读/短写/errno/资源/并发/安全/协议/可观测性）逐条给证据见 `03-审查报告.md`。

## 重写（v2）里我要改掉的

- 用 `struct conn` 把「读到哪、写到哪」显式存起来（`roff/rlen`、`woff/wlen`、`last_active`），
  换掉现在「一个请求一整块 `rbuf` + 一个出口 `goto done`」的形状。
- `poll` → `epoll_create1` + `EPOLLET`：accept 循环到 `EAGAIN`、read 循环到 `EAGAIN`、
  **只有写不完才注册 `EPOLLOUT`**（写完立刻摘，否则事件循环空转）。
- `close()` 之前先 `epoll_ctl(DEL)`（现在没有 epoll，所以这个坑还没机会踩）。
- keep-alive：把 `hdr_end` 之后的残余字节 `memmove` 到队头，继续解析下一个请求（现在直接丢弃）。
- 空闲超时：`epoll_wait` 的超时 + 每个连接 `last_active`（现在 `HTTPD_IDLE_MS=-1`，故意不设）。
