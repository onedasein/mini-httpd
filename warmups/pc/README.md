# 目标: `pthread` + 互斥锁 + 条件变量，固定大小环形缓冲
  
# 验收: `make tsan`编译运行无数据竞争告警

1. **有界(cap固定)** —— “固定大小环形缓冲”的核心。 “生产者被消费者唤醒，消费者被生产者唤醒”的双向同步。
2. **阻塞语义**: push/pop都阻塞，没有返回值非0的“满了/空了”。
3. **关闭协议**: close() 置closed并broadcast；消费者pop到-1就退出循环。该协议避免消费者线程永远醒不来，测试挂死。是“优雅停机”的正解，也是e2e可收尾的前提。
4. **失败返回-1**， 绝不在被测函数里exit() （一条用例不能把整个测试进程带走）
5. **队列不创建线程**: 线程由main/测试自己起，队列只管数据 + 同步。否则，不可单测。
